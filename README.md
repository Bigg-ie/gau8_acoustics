# GAU-8 Acoustic Simulation

Current release: **1.2.0**

A client-side acoustic replacement for the **GAU-8/A Avenger** in **Arma 3**. The mod replaces the audible cannon report and supersonic projectile crack field for supported GAU-8 weapons while leaving aircraft systems, weapon ballistics, damage, magazines, projectiles, and impact behavior under the control of Arma 3 or the originating aircraft mod.

## Features

- Speed-of-sound propagation delay
- Close, medium, and distant cannon-report layers
- Distance-dependent report timbre and spectral balance
- Directional muzzle and cannon report
- Doppler behavior for approaching and receding aircraft
- Terrain and object obstruction
- Ground-interference response
- Environmental reflections and decay
- Dedicated cockpit presentation
- Continuous support for short and long bursts
- Supersonic projectile cracks based on Mach-wave geometry
- Distance-dependent spectral attenuation of projectile cracks
- Projectile-crack reflections and environmental decay
- AI firing-mode support
- Optional compatibility with RHSUSAF, Firewill, USAF, CUP, A-10-tastic, and JSRS Soundmod 2025

Compatibility components load only when their required addons are present.

## Acoustic model

The cannon report changes with distance, direction, aircraft motion, obstruction, and the surrounding environment. Distant observers hear the report after the visible firing event because sound propagation is delayed.

The supersonic projectile crack field is modeled separately from the cannon report, allowing listeners near the projectile flight path to hear the crack independently of the delayed report arriving from the aircraft.

Cockpit listeners receive a dedicated internal presentation rather than the same external sound heard by observers outside the aircraft.

## What the mod does not change

The mod does not intentionally alter rate of fire, ammunition capacity, damage, penetration, muzzle velocity, dispersion, recoil, tracers, projectile physics, aircraft flight models, aircraft systems, or loadouts.

## Installation

### Steam Workshop

1. Subscribe to the mod.
2. Enable it in the Arma 3 Launcher.
3. Enable any supported optional aircraft or sound mods.
4. Start Arma 3.

Do not load a local development build and the Workshop copy at the same time.

### Manual installation

Use the contents of the HEMTT release directory or the packaged release ZIP. A signed release contains the built PBOs, signatures, public key, and license generated by the release process.

## Optional compatibility

The base mod does not require RHSUSAF, Firewill, CUP, USAF, A-10-tastic, or JSRS.

Compatibility components activate only when their corresponding third-party addons are present.

Supported optional integrations include:

- RHSUSAF A-10A
- Firewill A-10C
- CUP A-10 variants
- USAF A-10C
- A-10-tastic
- JSRS Soundmod 2025
- RHSUSAF with JSRS Soundmod 2025

Compatibility is intended to preserve the aircraft, weapon, ammunition, and system behavior supplied by those mods while allowing this project to provide the GAU-8 acoustic layer.

## Multiplayer

Clients that should hear the replacement acoustic system need the mod loaded. Servers using signature verification should install the included public key and distribute the matching signed release.

## Building from source

Requirements:

- Arma 3
- Arma 3 Tools
- HEMTT
- Git
- PowerShell

Clone the repository:

```powershell
git clone https://github.com/Bigg-ie/gau8_acoustics.git
Set-Location .\gau8_acoustics
```

Development validation:

```powershell
hemtt check
hemtt build
```

Release build:

```powershell
hemtt check
hemtt release
```

Release output is written under `.hemttout\release`.

## Known limitations

- The model is a gameplay-oriented acoustic approximation rather than a full wave-propagation simulation.
- Sound speed is fixed at approximately 343 m/s.
- Atmospheric temperature, humidity, wind, and pressure are not currently used to vary propagation.
- Obstruction and ground response depend on Arma world geometry and script timing.
- Very low or unstable frame rates can reduce timing precision.
- Third-party updates can require compatibility maintenance.
